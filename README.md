start building this project in 2027.

## Goal
Create a small app where a user can add, edit, complete and delete tasks.

## Planned technologies
- C#
- .NET
- MySQL
- Git and GitHub

## Planned features
- Add and edit tasks
- Mark tasks as done
- Save tasks in a MySQL database
